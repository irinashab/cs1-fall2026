An image can replace a drawn door. The click boundaries still come from your code.

1. Add the image file

Use the supplied door.jpg. Save a new sketch as imagePractice, then use Sketch → Add File… to add it. Or just drag the image onto an open sketch. The filename in your code must match the file, including its extension and capitalization.

imagePractice/
  imagePractice.pde
  data/
    door.jpg

2. Declare, load, display

PImage door;

void setup() {
  size(600, 400);
  door = loadImage("door.jpg");
}

void draw() {
  background(230);
  if (door != null) {
    image(door, 80, 100, 120, 220);
  } else {
    fill(0);
    text("Check data/door.jpg", 40, 50);
  }
}

PImage door; declares a variable that can refer to an image object. loadImage() loads the file in setup(). image() draws it in draw(). Loading once avoids repeating file-loading work every frame. See the Processing loadImage() reference.

Before loading: door [null]

After successful loading: door [reference] → [image object]

This is a conceptual memory diagram. The variable holds a reference to the image object; it does not contain all the pixels inside a small value box. null means there is no object reference. The check avoids drawing a missing image.

image(door, 80, 100) uses three arguments: the image, x, and y. The five-argument form adds display width and height. Our example stretches the image to fit a 120 × 220 door, which may change its proportions.

3. Put the image on your door

Try it

  1. Run the separate image practice first.
  2. Add door.jpg to your saved oneDoor sketch too: each sketch needs its own data folder.
  3. Add the global PImage declaration and the loading statement in setup().
  4. Replace the door rectangle with the image at the same position and dimensions.
  5. Keep your room conditionals, mouse function, and key function.

When combining sketches, merge their contents into the existing setup() and draw(); do not paste in second copies of those functions.

Check your reasoning

Your image should appear only in room 0. Drawing it after all the room conditionals would make it appear on the other screen too. A displayed image does not automatically create a clickable area; the coordinate checks still do that job.

Checkpoint: Your image appears in the starting screen, and the door still opens and returns correctly. Images are optional in the final project; drawn shapes are welcome.
