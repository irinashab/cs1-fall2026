Load a sound when the sketch starts. Play it when the player takes an action.

1. Prepare the library and file

Use Processing’s library manager (Sketch → Import Library → Add Library…) to install the Sound library from the Processing Foundation if it is not already installed. Create a sketch named soundPractice and add the supplied ding.mp3 using Sketch → Add File….

2. Run a click-to-play sketch

import processing.sound.*;

SoundFile ding;

void setup() {
  size(600, 400);
  ding = new SoundFile(this, "ding.mp3");
  textSize(22);
}

void draw() {
  background(230);
  fill(0);
  text("Click to hear the sound.", 40, 60);
}

void mousePressed() {
  ding.play();
}

The import makes the library’s classes available. SoundFile ding; declares our sound variable. new SoundFile(this, "ding.mp3") creates the player for the file; this identifies this sketch. ding.play() starts playback. See the Processing SoundFile reference.

Try it

Predict what changes if you move ding.play(); into setup(). What if you put it directly in draw()?

Check your reasoning

In setup(), the sound starts once at launch. Directly in draw(), the sketch requests playback every frame. In mousePressed(), it requests playback once per mouse press.

3. Make the door produce a sound

In your one-door sketch, add the import, global sound declaration, and loading statement. Add the sound file to that sketch. Then place playback immediately after the successful room change, inside both conditions:

void mousePressed() {
  if (room == 0) {
    if (mouseX >= 80 && mouseX <= 200 &&
        mouseY >= 100 && mouseY <= 320) {
      room = 1;
      ding.play();
    }
  }
}

Try it

Test a click outside the door, a click inside it, and a click after entering the library. Only the successful entry should play the sound. Return home and enter again.

If you cannot hear the sound
  • Check that the Sound library is installed and the import is present.
  • Check the filename and the current sketch’s data folder.
  • Check your volume and audio output, then read the Processing console for errors.
  • Test the separate sound practice sketch to isolate the issue.

The example assumes a valid sound file. Loading can fail before playback; wrapping only play() in an error handler would not handle a loading failure.

Checkpoint: A successful door click changes the room and plays one sound. The final project requires at least two sound effects; this practice sketch uses one.
