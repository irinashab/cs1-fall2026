Use your one-door practice as a starting point for a story with three distinct paths. Your group’s choices should determine what happens next.

1. Map your story

Draw a starting screen with three arrows, one for each door. Label each destination and its outcome. Show how the player returns home. Keep the first version small enough to test.

State valueSceneWhat the player can do
0Starting screenChoose one of three doors
1Your first destinationExperience an outcome; return home
2Your second destinationExperience an outcome; return home
3Your third destinationExperience an outcome; return home

Change the descriptions to fit your story. Each path needs one or more possible endings; further branching is optional. Decide who will begin coding, who will check the logic, and who will prepare the story and media. Share decisions and rotate roles.

2. Build and test

  1. Save a new copy of your one-door sketch for the group project.
  2. Draw three doors in room 0 and label them.
  3. Add two more destination scenes to your if/else if chain. Use else for an appropriate remaining case, such as an unexpected room value.
  4. Inside the starting-screen click handler, use if/else if to select which door was clicked.
  5. Keep the return action and test each path before adding more story details.
  6. Add your sounds and any images after the transitions work.

If a single click changes rooms more than once, examine separate if statements that check a room value you just changed. Decide the starting-screen action in one branch before handling other scenes.

Need to compare with the completed one-door practice?

This reference combines the earlier pieces. It is a one-door example, not a completed Three Doors project. Add the door image and practice sound to your sketch using Sketch → Add File….

import processing.sound.*;

int room = 0;
PImage door;
SoundFile ding;

void setup() {
  size(600, 400);
  textSize(22);
  door = loadImage("door.jpg");
  ding = new SoundFile(this, "ding.mp3");
}

void draw() {
  if (room == 0) {
    background(230);
    fill(0);
    text("Click the door", 40, 45);
    if (door != null) {
      image(door, 80, 100, 120, 220);
    } else {
      fill(130, 80, 40);
      rect(80, 100, 120, 220);
    }
  } else if (room == 1) {
    background(30, 60, 90);
    fill(255);
    text("You found the library.", 40, 60);
    text("Press r to return.", 40, 100);
  }
}

void mousePressed() {
  if (room == 0) {
    if (mouseX >= 80 && mouseX <= 200 &&
        mouseY >= 100 && mouseY <= 320) {
      room = 1;
      ding.play();
    }
  }
}

void keyPressed() {
  if (key == 'r' || key == 'R') {
    room = 0;
  }
}

3. Test with a partner

ActionExpected result
Click each door from the startIts own destination appears.
Click between, above, or below doorsNo door opens and no entry sound plays.
Click in a destinationStarting-screen doors do not respond there.
Press r and RBoth return to the start.
Enter a path again after returningThe story starts in its intended reset state.

If you add variables for keys, points, or other story choices, decide which must reset on returning home. Returning to room 0 does not automatically reset other variables.

Final project checklist

  • One group sketch with every group member’s name in a comment at the top.
  • Three clickable doors or regions leading to three distinct story paths, each with at least one ending.
  • A variable that tracks the current room; exactly one current room at a time.
  • if, else if, and else controlling scenes or events; combine conditions where useful.
  • A way to return to the starting screen and reset story variables appropriately.
  • At least two sound effects. Images are optional.
  • The entire sketch folder, including data, submitted together.

Be ready to explain your state variable and how conditionals control your story when presenting.

Check your understanding

  1. Why is room global in this sketch?
  2. What is the value of true && false? Of true || false?
  3. Why do we load media in setup() and play a door sound in the click handler?
  4. What works in your group’s sketch, and what is the next change you will make?
