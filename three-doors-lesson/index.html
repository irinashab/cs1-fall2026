Build an interactive story that remembers the player’s location, responds to choices, and uses images and sounds.

Start here

Imagine three doors. Each opens into a different scene, and the player can return to choose again. With a partner, name the information the program must remember and one condition it must check.

We will build a one-door example together, then you will expand the idea with your group. Use Processing in Java mode. You should already be comfortable with setup(), draw(), basic drawing, and simple if statements.

How to use this lesson

Predict before running code. Keep short memory diagrams and test notes. Open “Check your reasoning” after making your own attempt. Create your sketches in Processing using the code examples on these pages.
