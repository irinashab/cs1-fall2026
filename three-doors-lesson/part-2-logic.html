A click should open a door only when the player is on the starting screen and the pointer is inside that door.

1. Combine true-or-false questions

A comparison such as mouseX > 200 produces a Boolean value: true or false. && means AND: both conditions must be true. || means OR: at least one must be true, including when both are true.

2. Predict the canvas

On a 600-pixel-wide canvas, the dividing lines are at x = 200 and x = 400. This AND condition selects the middle region, excluding those lines.

void setup() {
  size(600, 300);
}

void draw() {
  if (mouseX > width/3 && mouseX < 2*width/3) {
    background(234, 15, 160);
  } else {
    background(255);
  }
  stroke(0, 0, 240);
  strokeWeight(3);
  line(200, 0, 200, 300);
  line(400, 0, 400, 300);
}

Try it

Predict the background at mouseX values 100, 200, 300, 400, and 500. Then run the sketch and test.

Next add && mousePressed to the condition. Predict what must now be true for the background to turn pink.

Check your reasoning

The original backgrounds are white, white, pink, white, white. After adding && mousePressed, the pointer must be strictly between the lines and a mouse button must be held down.

Predict the same five x positions for OR. Would OR work for “inside the middle region” if you simply changed AND to OR in the original condition?

Check your reasoning

The outer-region demo gives pink, white, white, white, pink. Changing the original condition to mouseX > 200 || mouseX < 400 would make it true for every x value: at least one side is always true.

3. A door has four boundaries

With the default rectangle mode, rect(80, 100, 120, 220) has left edge 80, right edge 200, top edge 100, and bottom edge 320. To include its edges, use:

mouseX >= 80 && mouseX <= 200 &&
mouseY >= 100 && mouseY <= 320

All four comparisons must be true. Being at the correct x position is insufficient if the pointer is above or below the door.

Try it

Classify these points as inside or outside: (100,150), (100,50), (250,150), (80,100). Write which comparison fails for each outside point.

Check your reasoning

Inside, outside (y is too small), outside (x is too large), inside (edges are included).

4. Build one door and a way home

This complete sketch builds on Part 1. Notice the outer if (room == 0): door clicks are meaningful only on the starting screen.

int room = 0;

void setup() {
  size(600, 400);
  textSize(22);
}

void draw() {
  if (room == 0) {
    background(230);
    fill(0);
    text("Click the door", 40, 45);
    fill(130, 80, 40);
    rect(80, 100, 120, 220);
  } else if (room == 1) {
    background(30, 60, 90);
    fill(255);
    text("You found the library.", 40, 60);
    text("Press r to return.", 40, 100);
  }
}

void mousePressed() {
  if (room == 0) {
    if (mouseX >= 80 && mouseX <= 200 &&
        mouseY >= 100 && mouseY <= 320) {
      room = 1;
    }
  }
}

void keyPressed() {
  if (key == 'r' || key == 'R') {
    room = 0;
  }
}

mousePressed without parentheses is a Boolean that tells you whether a button is held. void mousePressed() defines the function that responds to a new press. Use the function for a door-opening action. See the Processing mousePressed() reference.

In keyPressed(), each side of OR is a complete comparison. Write key == 'r' || key == 'R', not key == 'r' || 'R'. Click the sketch window first if it is not receiving keyboard input.

Try it

Test inside the door, above it, beside it, and on an edge. Enter the room, click again, and try both r and R. Move the door 20 pixels right and update both horizontal click boundaries to match.

Checkpoint: You have one clickable door and can return home. Save this sketch before adding media.
