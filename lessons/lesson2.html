Lesson 3: Variables and Conditionals

Big idea

Until now, our sketches have mostly followed a fixed list of drawing instructions. Today we will give a program a memory and let it make decisions.

By the end of this lesson, you should be able to:

  • give meaningful names to values,
  • change a value while a program runs,
  • use a variable to create motion,
  • ask a true-or-false question, and
  • make a program behave differently depending on the answer.

1. Numbers versus ideas

Consider this line:

ellipse(250, 150, 100, 100);

The computer can draw the ellipse, but it does not know what the numbers mean. Is 250 the center of the canvas? Is 100 the radius or the diameter? We may know now, but we might not remember later.

We can name the important values:

int centerX = 250;
int centerY = 150;
int diameter = 100;

ellipse(centerX, centerY, diameter, diameter);

A variable is a name for a value that the computer should remember. The drawing has not changed, but our intentions are now visible in the code.

2. Declaring a variable

A variable declaration has three parts:

int diameter = 100;
│   │          │
│   │          └── starting value
│   └───────────── name
└───────────────── data type

The data type tells Processing what kind of value the variable stores.

  • int stores a whole number, such as 42 or -7.
  • float stores a number with a decimal part, such as 2.5.
  • String stores text, such as "Hello".
  • boolean stores either true or false.
int score = 0;
float speed = 2.5;
String message = "Hello, Processing";
boolean gameOver = false;

For now, use int for most positions, sizes, and counters, and float when you need fractional values or smoother motion.

3. Assignment: changing a value

A variable stores one value at a time, but that value can change:

void setup() {
  int x = 5;
  x = 8;
  println(x);
}

This prints 8. The old value has been replaced.

Programs run in order, one statement at a time:

void setup() {
  int x = 3;
  x = x + 2;
  x = x * 2;
  println(x);
}

This prints 10. Each statement uses the value of x at that moment.

The statement

x = x + 1;

does not mean an algebraic equation. It means:

Take the current value of x, add 1, and store the result back in x.

Try it: trace the variable

Without running the program, determine what each line prints.

void setup() {
  int number = 4;
  println(number);

  number = number + 3;
  println(number);

  number = number * 2;
  println(number);
}

Trace the program on paper first. Then run it and compare the output with your prediction.

4. Variables create motion

The function draw() runs repeatedly. If a position changes a little during every frame, an object appears to move. 

int x = 50;

void setup() {
  size(600, 300);
}

void draw() {
  background(255);
  ellipse(x, height / 2, 50, 50);
  x = x + 2;
}

During each frame:

  1. the background erases the previous picture,
  2. the circle is drawn at the current value of x, and
  3. x changes before the next frame.

The changing value of x is part of the program’s state: information the program remembers from one frame to the next.

5. Where should the variable be declared?

Compare the previous sketch with this one:

void draw() {
  int x = 50;
  ellipse(x, height / 2, 50, 50);
  x = x + 2;
}

Here, x is created again and reset to 50 every time draw() begins. The circle does not move.

  • A variable declared outside the functions is global. It can preserve a changing value from one frame to the next.
  • A variable declared inside a function is local. It can be used only inside that function and is created again each time the function runs.

If an object must remember its position between frames, declare its position variable outside setup() and draw().

Try it: make something move

  1. Draw a shape using variables for its position.
  2. Change one position variable inside draw().
  3. Change the speed.
  4. Make the object move vertically instead of horizontally.

What happens when the object reaches the edge? At the moment, the program always performs the update. We need a way for it to make a decision.

6. A little unpredictability: random()

Processing’s random() function asks the computer to choose a number for us. This is useful for games, movement, colors, and experiments. 

void setup() {
  float number = random(1, 7);
  println(number);
}

This produces a float greater than or equal to 1 and less than 7. If we want a whole number that behaves like a six-sided die, we convert the result to an int: 

void setup() {
  int roll = (int)random(1, 7);
  println(roll);
}

The cast (int) discards the decimal part, so roll will be one of the integers from 1 through 6.

7. Asking a yes-or-no question

A Boolean expression is an expression whose value is either true or false. 

x > 100
x < width
x == 50
x != 0
x >= width - 25

The comparison operators are:

  • > greater than
  • < less than
  • >= greater than or equal to
  • <= less than or equal to
  • == equal to
  • != not equal to

Be careful: = performs assignment, while == asks whether two values are equal. 

x = 50;       // store 50 in x
x == 50       // ask: is x equal to 50?

8. The if statement

An if statement is a decision point. When execution reaches it, the program evaluates a Boolean expression. 

if (condition) {
  // runs only when the condition is true
}

For example:

void setup() {
  int roll = (int)random(1, 7);

  if (roll > 3) {
    println("You win!");
  }
}

If roll > 3 is true, the statement inside the braces runs. If it is false, that statement is skipped. The condition is checked when execution reaches the if statement—not continuously.

9. Choosing between two paths

An if–else statement chooses one of two paths. Exactly one path runs. 

void setup() {
  int roll = (int)random(1, 7);

  if (roll > 3) {
    println("You win!");
  } else {
    println("Try again.");
  }
}

Read it in English:

If the roll is greater than 3, print “You win!” Otherwise, print “Try again.”

10. Putting it together: bouncing off an edge

Let x store the circle’s position and speed store both how fast it moves and in which direction it moves. 

int x = 50;
int speed = 3;

void setup() {
  size(600, 300);
}

void draw() {
  background(255);
  ellipse(x, height / 2, 50, 50);

  x = x + speed;

  if (x > width - 25) {
    x = 0;
  }
}

When the center of the circle reaches width - 25, the circle teleports to the starting point.

Common pitfalls

  • Using = when you mean ==.
  • Putting a changing position variable inside draw(), where it is reset every frame.
  • Forgetting braces around the body of an if statement.
  • Testing the center of a shape when you really mean to test its edge.
  • Changing a variable before thinking about which value the condition will see.

When a sketch behaves unexpectedly, use println() to inspect the current values of important variables.

Takeaway

  • A variable gives a name to a value.
  • Assignment replaces the variable’s current value.
  • A global variable can preserve state between frames.
  • A Boolean expression evaluates to true or false.
  • An if statement makes execution selective.
  • Variables make motion possible; conditionals let the motion respond.
