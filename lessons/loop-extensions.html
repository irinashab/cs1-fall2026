1. The same repetition with while

These fragments produce the same output when placed inside setup():

for (int i = 0; i < 4; i++) {
  println(i);
}
int i = 0;
while (i < 4) {
  println(i);
  i++;
}

Both check the condition before each iteration. The while version places initialization before the loop and the update inside its body. The variable i in the while version remains in the surrounding block’s scope.

A for loop conveniently groups a counting pattern. A while loop often reads naturally when a condition is the main reason to continue. Either can express counted repetition; “known count” versus “unknown count” is a useful choice of style, not a language restriction.

Try it

Rewrite a terminating for loop of your own as a while loop. Explain which statement makes progress toward stopping. Check a case in which the body runs zero times.

2. A loop inside a loop

Predict the order and count of the lines printed:

void setup() {
  for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
      println("row " + row + ", col " + col);
    }
  }
}
Check your reasoning

Six lines: (0,0), (0,1), (0,2), (1,0), (1,1), (1,2). For each row, the inner loop initializes col to zero and runs three times. Two outer iterations × three inner iterations = six executions of println().

To draw a grid, derive x from the column and y from the row. If nested loops are inside draw(), the whole grid is generated during each frame; nesting does not create extra frames.

Try it

If a grid suits your composition, decide its rows, columns, spacing, and what each location means. Sketch it first. You do not need a grid just because nested loops exist.

3. Remainders and repeating choices

The % operator gives the remainder. For nonnegative integers, 7 % 3 is 1 and 8 % 2 is 0. A remainder of zero means the division is exact.

if (i % 2 == 0) {
  println("even index");
} else {
  println("odd index");
}

With indices starting at zero, even indices are 0, 2, 4, ... . These are the first, third, fifth, ... items. If you mean “every third item” while counting items from 1, use (i + 1) % 3 == 0.

Try it

Choose a repetition rule for your own design. Explain whether you are counting positions from zero or counting items from one, then check the first six results on paper.
