Lesson 9: While Loops and Nested Loops

A loop repeats a block of code while a condition is true. So far, we have used for loops to keep the initialization, condition, and update together. A while loop expresses repetition with the condition at the center.

Nested loops—a loop inside another loop—let us describe repetition at two levels, such as the rows and columns of a grid.

1. From if to while

Compare these two fragments. Each starts with n equal to 1.

A conditional

int n = 1;

if (n <= 3) {
  println(n);
  n++;
}

A loop

int n = 1;

while (n <= 3) {
  println(n);
  n++;
}

Before running them, predict what each fragment prints and the final value of n in each.

The if statement checks its condition once. If the condition is true, its body runs once, and execution continues after the block.

The while loop checks its condition again after completing the body. If the condition is still true, the body runs again.

The first fragment prints 1 and leaves n equal to 2. The second prints 1, 2, and 3, then leaves n equal to 4.

2. How a while loop runs

The general structure is:

while (condition) {
  // statements to repeat
}
  1. Check the condition.
  2. If it is false, skip the body and continue after the loop.
  3. If it is true, execute the entire body.
  4. Return to the condition check.

Consider:

int n = 2;

while (n <= 8) {
  println(n);
  n = n + 2;
}

println("Finished");

Trace the variable through the loop:

The output is:

The body runs four times. The condition is checked five times, including the final check that ends the loop.

Predict: What changes if the condition becomes n < 8?

A loop can run zero times

int n = 10;

while (n < 5) {
  println(n);
  n++;
}

println("After the loop");

The condition is false at the first check. The body never runs, and the only output is After the loop.

3. What makes the loop stop?

For the counting loops in this lesson, identify three things:

  • Initialization: Where does the variable get its starting value?
  • Condition: What must remain true for repetition to continue?
  • Update: How does the variable move toward the stopping condition?

In a while loop, these pieces are not all written on the same line. That makes it especially important to check them.

This loop does not stop. Trace it on paper; do not run it.

int n = 1;

while (n <= 5) {
  println(n);
}

Nothing changes n. It remains 1, so the condition remains true.

An update must also move in a useful direction. If you intend to count upward toward an upper boundary, subtracting from the counter will not produce the intended stopping behavior.

The condition is checked between iterations

Changing the variable inside the body does not immediately interrupt the body. Predict this fragment:

int n = 3;

while (n < 5) {
  n = n + 2;
  println(n);
}

It prints 5 once. The condition was true when n was 3. The update and print statement both execute before the condition is checked again.

4. Expressing the same repetition with for and while

These fragments print the same values.

Using for

for (int i = 0; i < 4; i++) {
  println(i);
}

Using while

int i = 0;

while (i < 4) {
  println(i);
  i++;
}

Both print:

0
1
2
3

A for loop is convenient when initialization, a condition, and a regular update naturally belong together. A while loop is useful when the condition is the clearest description of why repetition should continue.

Both can express counted repetition. A while loop is not restricted to situations with an unknown number of iterations.

There is also a scope difference: the for loop declares i inside its header, so that name is unavailable after the loop. The while version declares i in the surrounding block, where it remains available after the loop.

Example: repeat until a value reaches a threshold

int amount = 3;
int doublings = 0;

while (amount < 100) {
  amount = amount * 2;
  doublings++;
}

println(amount);
println(doublings);

Here, the condition describes the goal: keep doubling while the amount is below 100.

Trace it: What are the final values? Does the amount have to become exactly 100?

5. Drawing with a while loop

This complete sketch draws vertical lines:

void setup() {
  size(400, 300);
  background(255);

  int x = 20;

  while (x < width) {
    line(x, 0, x, height);
    x = x + 40;
  }
}

Before running it, determine:

  • The first three values of x.
  • The last value used to draw a line.
  • The number of lines.
  • The value of x when the loop ends.

The loop runs in setup(), so the drawing is generated once.

A while loop inside draw() still runs within one frame

Putting the same loop inside draw() would not draw one line per frame. Each call to draw() would execute the entire loop before finishing that frame.

To change something across frames, keep its state between calls and update it a little during each call.

Do not use a loop inside draw() to wait for a mouse press. The function needs to finish so the sketch can continue responding and drawing. Use an event function such as mousePressed(), or check a condition during successive calls to draw().

6. Nested loops: one complete loop for each outer iteration

A nested loop is a loop inside another loop. Start with console output:

void setup() {
  for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
      println("row = " + row + ", col = " + col);
    }
  }
}

Predict the output before reading further. For each value of row, the inner loop runs completely:

row = 0, col = 0
row = 0, col = 1
row = 0, col = 2
row = 1, col = 0
row = 1, col = 1
row = 1, col = 2
  1. The outer loop starts with row = 0.
  2. The inner loop starts with col = 0 and completes its three iterations.
  3. The outer loop updates row to 1.
  4. The inner loop starts again with a new col = 0.
  5. After that inner loop finishes, the outer loop updates row to 2 and stops.

The outer variable stays unchanged while the inner loop runs.

Here, the print statement executes 2 rows × 3 columns = 6 times.

Multiplication works because the inner loop runs three times for every outer iteration. If the inner limit depends on the outer variable, its number of iterations may vary.

7. From row and column numbers to screen coordinates

A row and column identify a position in a grid. They are not yet pixel coordinates. We can calculate coordinates from them:

x = left margin + column number × horizontal spacing
y = top margin + row number × vertical spacing

These are formulas in words. The complete Processing sketch below draws three rows of five circles:

void setup() {
  size(400, 280);
  background(255);

  int rows = 3;
  int columns = 5;
  int spacing = 60;

  for (int row = 0; row < rows; row++) {
    for (int col = 0; col < columns; col++) {
      int x = 50 + col * spacing;
      int y = 50 + row * spacing;

      ellipse(x, y, 24, 24);
    }
  }
}

The first few positions are:

005050
0111050
0217050
1050110
11110110

The circle diameter is 24. The spacing is 60. These are separate choices: spacing controls the distance between centers, while diameter controls the size of each circle.

Predict:

  • How many circles are drawn?
  • Where is the circle in row 2, column 4?
  • What changes if spacing becomes 40?
  • What changes if columns becomes 6?

Which loop comes first?

In this version, rows are outside and columns are inside, so the program draws one row at a time.

If you exchange the loops while keeping the coordinate formulas tied to row and col, the same grid positions are visited column by column. The order changes; the final image can remain the same.

Order can affect the image when shapes overlap or drawing choices depend on previous iterations.

8. Nested loops using while

The same structure can be written with while:

void setup() {
  size(400, 280);
  background(255);

  int rows = 3;
  int columns = 5;
  int spacing = 60;

  int row = 0;

  while (row < rows) {
    int col = 0;

    while (col < columns) {
      int x = 50 + col * spacing;
      int y = 50 + row * spacing;

      ellipse(x, y, 24, 24);
      col++;
    }

    row++;
  }
}

Notice where col is initialized: inside the outer loop, before the inner loop. Each row needs its own run through the columns, beginning at zero.

If you declare and initialize col only once before the outer loop, it reaches 5 after the first row. Unless you reset it, the inner condition is already false for every later row.

Also notice the two updates:

  • col++ advances through the current row.
  • row++ advances after that row is complete.

9. Conditions inside a grid

A condition inside the inner loop can make a decision for every cell. This fragment identifies cells in the first row or first column:

if (row == 0 || col == 0) {
  fill(0);
} else {
  fill(200);
}

Place the condition before the drawing statement inside the inner loop.

Alternating patterns with remainder

The remainder operator % helps describe repeating patterns.

7 % 2   // 1
8 % 2   // 0

For nonnegative integers, an even number has remainder 0 when divided by 2; an odd number has remainder 1.

To alternate choices across both rows and columns:

if ((row + col) % 2 == 0) {
  fill(0);
} else {
  fill(255);
}

Moving one column or one row changes the parity of row + col, so neighboring cells receive different colors.
