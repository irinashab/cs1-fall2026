Final Project Toolbox: Depth, Motion & Words

One Last Toolbox

You already know enough to build something of your own. Today: three ideas you can borrow for your final project. Try them, pick what fits, and make it yours. You do not need to use all three—or any of them.

Each example below is a complete, separate Processing sketch. Run them one at a time in a new sketch.

1. Give It Depth: A Taste of 3D

Use P3D to add a depth coordinate. Positive x goes right, positive y goes down, and positive z comes toward you. Move the mouse to turn this box.

void setup() {
  size(600, 400, P3D);
}

void draw() {
  background(25);
  lights();
  noStroke();

  pushMatrix();
  translate(width/2, height/2, 0);
  rotateX(map(mouseY, 0, height, -PI, PI));
  rotateY(map(mouseX, 0, width, -PI, PI));
  fill(100, 180, 255);
  box(120);
  popMatrix();
}

translate() places the local origin; box() draws around it. rotateX() and rotateY() turn the coordinates, using radians. lights() adds shading. The pushMatrix()/popMatrix() pair keeps these transformations from affecting the next object. Rotation order matters.

Make it yours: replace box(120) with sphere(70), then add a second object with its own transformation pair. A tiny sculpture, a robot, a strange planet?

For more details check out P3D Tutorial.

2. Give It Motion: PVector

A PVector bundles related components such as x and y. Use one for position, one for velocity, and one for acceleration: acceleration changes velocity; velocity changes position. This little follower accelerates toward the mouse.

PVector position;
PVector velocity;

void setup() {
  size(600, 400);
  position = new PVector(width/2, height/2);
  velocity = new PVector(0, 0);
}

void draw() {
  background(25);
  PVector target = new PVector(mouseX, mouseY);
  PVector acceleration = PVector.sub(target, position);
  acceleration.normalize();
  acceleration.mult(0.15);

  velocity.add(acceleration);
  velocity.limit(4);
  position.add(velocity);

  noStroke();
  fill(255, 190, 70);
  ellipse(position.x, position.y, 24, 24);
}

PVector.sub(target, position) creates a vector pointing from the follower to the target. normalize() keeps its direction and makes its length 1 (a zero vector stays zero); mult(0.15) sets the acceleration strength. limit(4) caps speed.

Watch the difference: position.add(velocity) changes position. The two-argument PVector.sub(target, position) returns a new vector without changing either input.

Make it yours: give your own class position and velocity vectors. Try several followers with different speeds. This example can overshoot and orbit the mouse—it does not brake to a stop. Add a boundary rule if your project needs one.

For more details check out PVector Tutorial.

3. Give It a Voice: Strings and Moving Type

Text can be more than a score label. Draw a word one letter at a time and let it dance. Press a key to change the word.

String word = "HELLO";

void setup() {
  size(600, 400);
  textSize(48);
  textAlign(CENTER, CENTER);
}

void draw() {
  background(25);
  fill(255, 150, 190);
  float spacing = 55;
  float startX = width/2.0 - (word.length() - 1) * spacing/2;
  for (int i = 0; i < word.length(); i++) {
    float y = height/2.0 + sin(frameCount * 0.05 + i) * 30;
    text(word.charAt(i), startX + i * spacing, y);
  }
}

void keyPressed() {
  if (word.equals("HELLO")) {
    word = "DANCE";
  } else {
    word = "HELLO";
  }
}

length() gives the number of characters; charAt(i) gets one character, starting at index 0. The loop stops before word.length(). Here, sin() makes a repeating wave; adding i puts each letter at a different point in that wave.

Two rules to keep: compare text with .equals(), rather than ==. Strings are immutable: methods such as replace() return new text, so save the result: word = word.replace("HELLO", "WOW");

For more details check out Strings and Drawing Text.

Make it yours: a kinetic poem, expressive dialogue, a word game, or a title that reacts to the mouse. Change the wave height, spacing, color, or words.

Project Sparks

  • A creature with opinions: a character follows the mouse and displays a message when you interact. Start with one creature; add personalities later.
  • A pocket universe: a few rotating 3D objects with different colors and speeds. Start with two shapes; add controls or labels later.
  • Words with moods: make a word bounce, tremble, or drift to match its meaning. Start with one word; add user choices later.
  • A tiny celebration: particles move with velocity and gravity while a message appears. Start with a fixed array of particles; add trails or resets later.

Flocking is a possible stretch: separation avoids crowding, alignment matches nearby directions, and cohesion moves toward nearby neighbors. Get several independent movers working first; the follower demo above is not a full flocking system.
