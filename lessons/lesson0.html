What is Computer Science?

Computer science is a fascinating and multifaceted field that goes far beyond the tools and devices it employs. As computer scientists Michael R. Fellows and Ian Parberry stated in an article for Computing Research News:

“Computer Science is no more about computers than astronomy is about telescopes, biology is about microscopes, or chemistry is about beakers and test tubes. Science is not about tools. It is about how we use them and what we find out when we do.”

Michael R. Fellows and Ian Parberry, Computing Research News

So, what exactly is computer science? One useful definition comes from Professors Norman Gibbs and Allen Tucker. According to them, computer science is the study of algorithms, including:

  1. their formal and mathematical properties;
  2. their realization in computer hardware;
  3. their expression in programming languages;
  4. their application to solving important problems.

To understand this definition, we first need to understand what an algorithm is. Merriam-Webster defines an algorithm as:

"A procedure for solving a mathematical problem in a finite number of steps that frequently involves repetition of an operation; broadly, a step-by-step method for accomplishing some task."

Merriam-Webster Dictionary

In simpler terms, an algorithm is a finite, precise sequence of instructions for solving a problem or performing a task. Algorithms aren’t just theoretical constructs—they are everywhere in our daily lives. In this course, we’ll practice taking informal, everyday procedures and turning them into precise, executable instructions.

Think–Pair–Share

Describe an everyday procedure that might be an algorithm. Are all its instructions precise? Does it always end?

Starting with Processing

Processing is a free programming environment designed to make visual programs easy to create. Processing programs are called sketches, and each sketch is stored in its own folder. We will use Processing in Java mode, the default mode.

Installing Processing at Home

Download the current version for your operating system from the official Processing download page.

  • Windows: Download the Windows version, extract the downloaded .zip file, and open Processing from the extracted folder.
  • macOS: Download the version for your Mac, open the downloaded file, and drag Processing to your Applications folder.
  • Linux: Download and extract the Linux archive, open the extracted folder, and run the Processing executable.

Start Processing and make sure Java appears in the mode menu in the upper-right corner.

Processing consists of:

  • The Processing Development Environment (PDE).
  • A graphics-focused collection of functions.
  • Java syntax together with a simplified programming environment.
  • An active online community at processing.org.

Processing Environment

The Processing Development Environment (PDE) consists of a simple text editor for writing code, a message area, a text console, tabs for managing files, a toolbar with buttons for common actions, and a series of menus. See the Processing Environment documentation for more details. You can customize the PDE through Preferences.

Your First Sketch

Create a new sketch, type the following code, and click the Run button: 

size(500, 400);
background(240);

ellipse(250, 200, 100, 100);

Processing places the origin, (0, 0), in the upper-left corner of the canvas. The first two numbers in ellipse(250, 200, 100, 100) locate the center of the ellipse; the last two give its width and height.

Try each of these changes, running the sketch after every change:

  1. Change the size of the canvas.
  2. Move the circle to a different location.
  3. Change the circle into an ellipse.
  4. Add a rectangle.

For more details, see Coordinate System and Shapes.

Color and Transparency

Functions such as background(), stroke(), and fill() control color. A fourth color value controls transparency (the alpha value): 0 is completely transparent and 255 is completely opaque. 

size(500, 400);
background(240);

stroke(0);
fill(255, 120, 0, 170);
ellipse(220, 200, 160, 160);

noStroke();
fill(50, 180, 255, 120);
rect(240, 120, 180, 140);

See the Processing tutorial Color for a fuller explanation.

Comments

Comments are notes for people reading the program; Processing ignores them. Use two forward slashes for a single-line comment: 

// Draw a circle in the center of the canvas
ellipse(250, 200, 100, 100);

For a comment that extends over several lines, place it between /* and */: 

/*
  This sketch explores
  Processing’s coordinate system.
*/
