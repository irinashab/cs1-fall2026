Programming Assignment 2

Variables, Decisions, and Motion

In this assignment, you will use variables to store information, change values while a program runs, and make decisions with if, else if, and else statements.

By the end of the assignment, you should be able to:

  • choose meaningful variables for a program,
  • trace how variable values change,
  • write Boolean expressions using comparison operators,
  • choose among several possible actions, and
  • combine changing state with conditionals to create motion.

Starter Files

Download and unzip the starter folder: Programming Assignment 2 starter files .

The folder contains colorChange.pde, rollOver.pde, and ball.pde.

Getting started

  1. Create a folder named yourNameProgrammingAssignment2.
  2. Save every sketch for this assignment inside that folder.
  3. Give each sketch a descriptive name.
  4. Read each program aloud and predict its behavior before running it.

Use camelCase for names made from several words, such as circleSize, xSpeed, and backgroundColor. Choose names that explain what each value represents.

Comments should explain what important variables represent and why their values change. Do not comment every line simply by translating the code into English.

Part 1. Random Grade

Ask the computer to generate a score and report the corresponding letter grade.

Score Grade
90–100A
80–89B
70–79C
60–69D
0–59F

Requirements

  1. Declare an int variable named score.
  2. Assign it a random integer from 0 through 100, inclusive.
  3. Print the score to the console.
  4. Use an if–else if–else chain to print the correct letter grade.
  5. Run the sketch several times and verify that the reported grades are correct.

Remember that random(101) produces a value from 0 up to, but not including, 101. Because random() returns a float, you must convert the result to an int.

Your executable statements belong inside setup(). Conditions are checked from top to bottom, and only one grade should be printed.

Part 2. Choose One Interactive Sketch

Complete one of the following starter sketches. Save your completed sketch with a new, descriptive name.

Option A: colorChange.pde

  1. Complete the blue-color change controlled by the vertical mouse position.
  2. When the mouse is pressed, set the background to a color of your choice.
  3. Keep all three color values between 0 and 255.
  4. Add comments explaining the conditions and the changing variables.

The provided call to constrain() keeps a value within a specified range. Look it up in the Processing reference and use it where needed.

Option B: rollOver.pde

  1. Divide the canvas into four quadrants.
  2. Use nested if statements to determine which quadrant contains the mouse.
  3. Highlight only that quadrant.
  4. Add comments explaining the purpose of each condition.

For this assignment, do not combine conditions using &&, ||, or !. Use nested if statements when you must ask a second question.

Part 3. Bouncing Ball

Begin with ball.pde. The starter ball moves horizontally and teleports back to the left after leaving the canvas. Change the program so the ball moves in two dimensions and bounces from all four edges.

Requirements

  1. Store the horizontal and vertical positions in variables.
  2. Use separate variables for horizontal and vertical speed.
  3. Update both positions during every frame.
  4. Reverse the appropriate speed when the ball reaches an edge.
  5. Keep the entire ball inside the canvas—not just its center.
  6. Use separate if statements for the boundaries.

Do not use &&, ||, or ! in this part. Think carefully about the radius of the ball and the order in which position and speed are updated.

If you finish early

Choose one or more extensions:

  • Change the ball’s color when it hits an edge.
  • Give the ball a random starting position or speed.
  • Change the canvas size and make sure the program still works.
  • Add a second ball with different position and speed variables.

Before writing each condition, say the yes-or-no question aloud. For example: “Has the left side of the circle reached the left edge of the canvas?”

Code expectations

  • Use meaningful camelCase variable names.
  • Avoid unexplained magic numbers.
  • Indent the contents of every function and conditional block.
  • Use braces consistently.
  • Add useful comments.
  • Run and test every sketch before submitting it.

You should be able to explain what each variable stores, when its value changes, and why each condition is true or false.
