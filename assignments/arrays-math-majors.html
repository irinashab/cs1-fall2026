Array Practice — Mandatory (Math/CS Majors)

Optional for everyone else — can be done for extra credit.

Task 1 — Squaring elements of an array

Work with an array of 10 integers. Square each element and store the result back into the same array.

Steps

  1. Declare an integer array of length 10.
  2. In setup(), fill the array using a loop with any simple pattern you like.
  3. Print the first and last elements before making any changes, using a[0] and a[a.length - 1]. Label this line BEFORE.
  4. Using a single loop, square each element in place — that is, store the squared value back into the same slot. Do not create a second array.
  5. Print the first and last elements again. Label this line AFTER.
  6. As a comment in your code, explain in one or two sentences why you wrote the loop condition as i < a.length rather than i <= a.length.

Task 2 — Summing consecutive elements

Work with an array of 10 integers. Replace each element (except the last one) with the sum of that element and the next one. Do not modify the last element.

Steps

  1. Declare an integer array of length 10.
  2. In setup(), fill the array using any simple pattern you like.
  3. Print a[0], a[1], and a[a.length - 1]. Label this line BEFORE.
  4. Using a loop, replace each element (except the last) with the sum of that element and the next one. Your loop bound must be chosen so the loop never reads past the end of the array.
  5. Print the same three values again. Label this line AFTER.
  6. As a comment in your code, answer this question in one or two sentences: when you update the array left to right, can a[i + 1] already contain a changed value by the time you read it? Explain why or why not.

Task 3 — Calculating a sum

Work with an array of 5 integers. Compute the sum of all elements, then compute the sum of the elements at even indices only.

Steps

  1. Declare an integer array of length 5.
  2. In setup(), fill the array using any simple pattern you like.
  3. Print the first and last elements.
  4. Using a loop, compute the sum of all elements. Store it in a variable named sumAll.
  5. Using a second loop that starts at index 0 and increments by 2 (so it visits indices 0, 2, and 4 only), compute the sum of the elements at even indices. Store it in a variable named sumEvenIndex.
  6. Print both sums with clear labels.
  7. As a comment in your code, explain in one sentence why starting at 0 and incrementing by 2 visits exactly the even indices.

Task 4 — Working with colors

Build an array of 50 random RGB colors and use them to paint shapes of your choice.

Steps

  1. Declare a color array of length 50. The color type stores an RGB value, so each slot in this array holds one color: 
    color[] palette = new color[50];
  2. In setup(), set the canvas size, disable the stroke, and fill the color array using a loop with random colors. Each slot palette[i] should be assigned a color(...) value built from random red, green, and blue components.
  3. Print the first and last colors in the array so you can verify the fill worked.
  4. In draw(), clear the background.
  5. Using a loop, draw exactly 50 shapes. Shape number i must use palette[i] as its fill. Do not call random() inside draw() for color.
  6. If your artwork is static, you may call noLoop() at the end of draw().

Submission

  • Each sketch must run without errors and must include the required prints and comments.
  • Place all sketch folders inside one parent folder, compress (zip) that parent folder, and submit the single .zip file.
